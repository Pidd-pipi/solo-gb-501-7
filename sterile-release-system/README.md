# 无菌包装生产放行系统（Sterile Release System）

面向医疗器械无菌包装工厂的生产放行管理：产线 → 批次登记 → 检验样本 → 检验录入 → 不合格自动待复测 → 放行审批（放行/隔离/返工/拒收）→ 哈希链审计。

纯前端实现，**零构建、零后端**：打开 `index.html` 即可使用，数据存浏览器 `localStorage`；领域逻辑为 UMD 模块，可在 Node 中直接测试。

## 运行

```bash
# 方式二：本地静态服务

# 访问 http://localhost:8080
```

## 多页签并发安全

多个页签同时打开时，系统通过三层机制避免“过期页面覆盖新判定”：

1. **写前合并（hydrate）**：每个写操作落盘前先从 `localStorage` 读取最新状态再合并写入，过期页签不会整份覆盖他人数据；全局 `revision` 单调推进。
2. **跨页签实时同步**：监听浏览器 `storage` 事件，其他页签登记批次/录入检验后，本页签的审批列表、队列、徽标立即自动刷新；正在打开的放行决定弹窗若依据版本已变化，会显示冲突横幅并禁用提交，必须按最新数据重新打开（数据重置导致版本回绕也能正确同步）。
3. **提交前复核 + 批次乐观锁**：批次带数据版本 `rev`，决定弹窗打开时记录该版本（表单隐藏字段 + 弹窗提示 `vN`）。提交时领域层先 hydrate 到最新数据，再校验 `expectedRev === batch.rev`，然后**按当前数据重新执行四项放行条件核查**：
   - 版本不一致 → `REV_MISMATCH` 冲突，决定不写入；
   - 两个页签持同一版本先后提交 → 先落盘者生效，后到者看到终态得到 `TERMINAL` 冲突（“批次已由其他操作决定为已放行/拒收”），恰好一条成功；
   - 即使版本相同，若他页签刚把检验结果改为不合格，RELEASE 仍会被最新的放行核查拦截。
   每条决定的审计记录包含「依据数据版本：第 N 版」。

## 存储损坏处理（不静默丢数据）

持久层读取时做严格结构校验（JSON 合法性、五个必备数组、seq、revision 类型）：

- 损坏（截断、手工改写、结构缺失、版本号类型错误）→ 启动进入显式报错页，`storageHealth()` 返回 `STATE_CORRUPT`，`getLoadError()` 给出具体原因；
- 损坏期间所有写操作在 hydrate 阶段即被拒绝，**绝不会用空状态覆盖损坏原文**；
- 仅质量管理员可执行「备份损坏数据并恢复空库」：原文先复制到取证键 `sr_system_state_v1.corrupt-backup`，再写入合法空状态；运行中他页签写入损坏数据也会实时弹出恢复页；
- 旧版本数据缺少 `revision` 字段时按 0 兼容迁移，不算损坏。

## 主线操作路径

1. **操作员 → 批次队列**：「＋ 登记批次」选择产线/产品/数量/样本数，批次号自动生成（如 `B20260912-001`），同时生成待检样本，批次状态 `待检`。
2. **检验员 → 检验工作台**：
   - 待检样本录入密封强度（数值，1.5~3.0 N/15mm 自动判定）、外观、无菌屏障、标签；
   - 任一项不合格 → **样本自动进入「待复测」，批次自动变「待复测」**；
   - 「发起复测」后录入第二轮：复测合格 → 解除待复测；复测仍不合格 → 最终不合格，批次进入「待审批」。
3. **审批员 → 放行审批**：每批展示四项放行条件实时核查清单，提交决定弹窗中：
   - 条件全部满足才能选「放行」；
   - 不满足时「放行」锁定，并逐条列出拦截原因，只能选隔离/返工/拒收。
4. **隔离与返工联动**：
   - 隔离 → 批次 `已隔离`，调查后可在审批页重新处置（改判放行/返工/拒收）；
   - 返工 → 原样本作废（检验历史保留），批次 `返工中`；检验员「返工后补取样」后批次自动回 `待检`，复检全合格再放行。
5. **审计记录**：登记、录入、复测、补样、决定、产线维护均留痕，含操作者（姓名+角色）、请求标识（`REQ-时间戳-序号`，全局唯一）、字段级变更（前值→后值）；FNV-1a 哈希链使任何增删改都会断链，页面可一键校验。

## 放行硬条件（不满足即拦截并说明原因）

1. 所有有效样本均有检验记录；
2. 无待检样本；
3. 无待复测样本；
4. 无最终不合格结果。

## 统一状态标签（批次队列与放行审批共用）

`待检` `待复测` `待审批` `已放行` `已隔离` `返工中` `拒收`；
样本：`待检` `合格` `不合格→自动待复测` `待复测` `最终不合格` `已作废`。
